# YingcaiCup-kskbl

**会听会变声的智能终端** —— 在 ROCK 5B+（RK3588）上做语音识别、变声、音色克隆，全部本地运行。

- 插上 USB 声卡 → 说话 → 拔掉 → 识别 → 变声 → 插回 → 播放
- 屏幕用 1.54" SPI 屏（**直连 ROCK，无任何额外控制器**）
- 两条变声路线：**DSP 相位声码器**（0 参数，0.4 秒）和 **CosyVoice2 音色克隆**（781 M 参数，像特定人）
- 语音指令切换音色：「我是曼波」/「我是瓦瓦」
- 语音关机：「曼波关机」/「瓦瓦关机」
- 开机自启，说一句就能断电

## 快速开始

### 板子侧（运行环境）

系统依赖：

```bash
sudo apt install -y libportaudio2 python3-libgpiod python3-spidev python3-pil
# CosyVoice2 编译还需要：
sudo apt install -y build-essential cmake libpcre2-dev
```

Python 环境：

```bash
python3 -m venv ~/proj/venv
source ~/proj/venv/bin/activate
pip install -r requirements.txt
```

### 部署

```bash
cd ~/proj/kskbl
sudo bash deploy/apply.sh      # 一键部署 + 重启 + 校验版本
```

### 使用

```
上电 → 屏幕「请插上声卡」
  ↓ 插上 USB 声卡
🔔 短嘀 → 录音
  ↓ 说话…
  ↓ 拔掉声卡
识别 → 屏幕显示文字 + 「请插上声卡播放」
  ↓ 插回声卡
🔊 播放变声结果
```

## 五条必须记住的铁律

1. **改完代码必须重启服务** —— 用 `deploy/apply.sh` 并核对版本时间
2. **声卡按名字或 VID:PID 找，不要用卡号** —— 每次插拔都会变
3. **音色资产放 `~/proj/voices/`**，不能放 `/tmp`
4. **`pkill -f` 会杀掉自己** —— 用方括号技巧或按 PID 杀
5. **关机指令必须带音色名** —— 防误触断电

详见各文档里的踩坑记录。
