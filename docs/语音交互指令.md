## 1. 触发方式

`--trigger` 参数控制「什么时候开始录音」：

| 模式 | 触发条件 | 用途 |
|---|---|---|
| **`usb`** | 插上 USB 声卡开始，拔下结束 | **当前使用**，演示时最直观 |
| `auto` | 定时循环（`--gap` 秒间隔） | 无人值守测试 |
| `jack` | 板载 3.5mm 耳机孔插入 | 备用 |

### 1.1 为什么用 USB 声卡插拔（而不是麦克风插拔）

**C-Media `0d8c:0014` 这颗芯片的硬件就不支持麦克风插拔检测。**

查证过程：

```bash
$ amixer -c 3 controls
numid=3 name='Mic Playback Switch'
numid=4 name='Mic Playback Volume'
numid=7 name='Mic Capture Switch'
numid=8 name='Mic Capture Volume'
numid=9 name='Auto Gain Control'
numid=5 name='Speaker Playback Switch'
numid=6 name='Speaker Playback Volume'
# 没有 Jack / Plug / Insert 类控件
```

`/proc/asound/card3/usbmixer` 里也只有 Unit 9 / 10 / 13 的音量开关，**没有 jack unit**。

而 USB 声卡**整块插拔**是 USB 层事件，100% 能检测：

```bash
$ cat /proc/asound/card3/usbid
0d8c:0014
```

### 1.2 按 VID:PID 认设备，不按卡号

**ALSA 卡号每次插拔都可能变**（实测见过 card 3/4/5），所以：

```python
for path in glob.glob("/proc/asound/card*/usbid"):
    if open(path).read().strip().lower() == "0d8c:0014":
        return True
```

每次插上都重新解析卡号和 sounddevice 索引。

### 1.3 验证插拔检测是否有效

```bash
~/proj/venv/bin/python tools/watch_usb.py
```

只在状态变化时打印：

```
13:06:17  ✅ 已插入   (/proc/asound/card3/usbid)
13:07:02  ❌ 已拔出
13:07:15  ✅ 已插入   (/proc/asound/card3/usbid)
```

## 2. 切换音色

### 2.1 两种说法

| 说法 | 等价于 |
|---|---|
| 「我是曼波」 | 切换到曼波音色 |
| 「切换到音色1」 | 同上 |
| 「我是瓦瓦」 | 切换到瓦瓦音色 |
| 「切换到音色2」 | 同上 |

### 2.2 ⚠️ ASR 对这两个词的识别极不稳定

实测收到过的写法：

```
「我是慢播」   ← "波" → "播"
「我是漫播」   ← "曼" → "漫"
「我是漫步」   ← "波" → "步"
「我是娃娃」   ← "瓦" → "娃"
「我是哇哇」   ← "瓦" → "哇"
```

**穷举不可行**（曼/慢/漫/满/蛮 × 波/播/拨/博/步 = 25 种组合，还会继续冒新的）。

**解法：同音字字符类正则**

```python
_VOICE_PATTERNS = [
    # 「我是曼波」的各种同音写法
    ("manbo", re.compile("[曼慢漫满蛮蔓][波播拨博簸步]")),
    ("wawa",  re.compile("[瓦娃哇挖袜][瓦娃哇挖袜]")),

    # 「切换到音色1」/「音色一」。ASR 常把"音色"识别成同音的"银色"
    ("manbo", re.compile("[音银][色瑟]\\s*[1一壹]")),
    ("wawa",  re.compile("[音银][色瑟]\\s*[2二贰]")),
]
```

不要求「我是」前缀 —— 句子里出现这个词就算命中。

别名：「哈基米」也算曼波。

### 2.3 幂等规则

| 当前音色 | 说的话 | 行为 |
|---|---|---|
| 瓦瓦 | 「我是曼波」 | ✅ **切换**到曼波，这句不念 |
| 瓦瓦 | 「我是瓦瓦」 | ✅ **不切换**，把整句当普通句子念出来 |
| 曼波 | 「我是曼波」 | ✅ **不切换**，整句念出来 |
| 曼波 | 「我是瓦瓦」 | ✅ **切换**到瓦瓦，这句不念 |

**核心规则：只有「目标音色 ≠ 当前音色」时才执行切换。**

实测验证：

```
识别文字: 哈基米欧南北绿豆，我是曼波，家人们谁懂啊？
🎚 提到「manbo」，但当前已是该音色，按普通句子处理
📺 显示：哈基米欧南北绿豆，我是曼波，家人们谁懂啊？
🎙 音色克隆（曼波音色）：……      ← 整句被完整念出
```

### 2.4 切换时的屏幕和声音

```
屏幕：「切换中…」（不显示那句话的内容 —— 说什么不重要）
声音：两声高音嘀（900 Hz）
```

## 3. 语音关机

### 3.1 ⚠️ 破坏性操作，做了双重确认

**第一重：必须说对当前音色名**

| 当前音色 | 必须说 | 光说「关机」 |
|---|---|---|
| 曼波 | 「曼波关机」 | ❌ 不触发 |
| 瓦瓦 | 「瓦瓦关机」 | ❌ 不触发 |

**第二重：整句表达关机**

```python
_SHUTDOWN_PATTERNS = {
    "manbo": re.compile("[曼慢漫满蛮蔓][波播拨博簸步][关關][机機]"),
    "wawa":  re.compile("[瓦娃哇挖袜][瓦娃哇挖袜][关關][机機]"),
}
```

### 3.2 会触发 vs 不会触发

| ✅ 会关机 | ❌ 不会 |
|---|---|
| 曼波关机 | 我要关机充电 |
| 慢播关机 | 关机键在哪 |
| 漫播关机！ | 关机之后怎么办 |
| 瓦瓦关机 | 不要关机 |
| 娃娃关机 | 关机（缺音色名） |
| 哇哇关机！ | 曼波关机（当前是瓦瓦） |

**16 个用例全部验证过。**

### 3.3 交叉行为

```
当前曼波 说「瓦瓦关机」→ 不关机，但会切换到瓦瓦音色
当前瓦瓦 说「曼波关机」→ 不关机，但会切换到曼波音色
```

因为「瓦瓦」「曼波」本身就是切换词。**合理**（你明确说出了另一个音色名），但演示时要知道。

### 3.4 执行过程

```
屏幕「关机中…」
  ↓
两声低音（400 Hz → 300 Hz）
  ↓
sudo -n poweroff
```

需要 `deploy/kskbl-sudoers` 里的免密规则（见 `docs/部署与开机自启.md`）。

## 4. 录音什么时候结束

### 4.1 USB 触发模式（当前）

```
插上声卡 → 立即开始录音（不倒数，只响一声短嘀 1200 Hz）
拔掉声卡 → 立即结束
```

**关闭了静音自动停**（`--silence-stop 0`），只听拔卡这一件事。

`--duration 30` 只是保险，防止忘了拔卡一直录。

### 4.2 自适应噪声门限（`auto` 模式用）

固定阈值在嘈杂环境里会失效：

```
环境噪声 -32 dBFS → level_ratio = 0.760
旧阈值 0.18      → 永远判定"有人在说话"
                → 静音永远累计不起来
                → 只能等 15 秒上限
```

改成**自适应**：每轮先安静录 0.6 秒测噪声基线，判定门限 = 「噪声 + N dB」。

```python
noise_db = audio.measure_noise_floor(calib, rate)   # 分块 RMS 的中位数
threshold = max(noise_db + margin_db, abs_speech_dbfs)
```

**用中位数而不是均值** —— 校准期间有人咳嗽不会把基线拉高（实测差 0.0 dB）。

### 4.3 margin 的物理上限

```
门限不能超过「说话音量 − 环境噪声」（≈ 信噪比）
```

| 环境噪声 | margin 15 的门限 | 正常说话(-20 dBFS) |
|---|---|---|
| −55 dBFS | −35（受 floor 限制） | ✅ 通过 |
| −42 dBFS | −27 dBFS | ✅ 通过 |
| −32 dBFS | −17 dBFS | ❌ 判成静音 |

如果 margin 调太高导致识别不到，说明环境太吵，根本办法是提高信噪比（麦克风靠近嘴、关空调）。

## 6. 完整流程（USB 触发模式）

```
待机「请插上声卡」
  ↓ 插上声卡
🔔 短嘀 → 立即录音（不倒数）
  ↓ 说话…
  ↓ 拔掉声卡
录音立即结束 → 裁掉首尾静音
  ↓
SenseVoice 识别（17~20 倍速）
  ↓
┌─ 命中「曼波关机/瓦瓦关机」？→ 关机
├─ 命中切换指令且音色不同？ → 「切换中…」→ 换音色 → 下一轮
└─ 普通句子
    ↓ 屏幕显示这句话
    ↓
    ├─ 瓦瓦音色 → DSP 波形变声（0.3~0.6 秒）→ 「请插上声卡播放」
    └─ 曼波音色 → CosyVoice 合成（8~20 秒，带进度条）→ 「请插上声卡播放」
  ↓ 插上声卡
🔊 播放变声结果
  ↓ 拔下
回待机
```
