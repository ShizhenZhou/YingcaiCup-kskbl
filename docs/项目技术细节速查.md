## 0. 一句话

**所有计算都在 ROCK 5B+ 板子上完成，电脑只用来编辑代码和传文件。**

```
电脑（Windows）                    ROCK 5B+（RK3588）
├── 编辑 .py 文件                  ├── 运行全部程序
```

## 3. 分贝阈值（重点）

### 3.1 三组不同的「分贝」，别搞混

| 名称 | 用途 | 范围 |
|---|---|---|
| **音量条映射** | 把 RMS 变成 0~1 画音量条 | 固定 **−70 ~ −20 dBFS** |
| **自适应 VAD 门限** | 判断「这一帧是不是有人在说话」 | 动态，随环境噪声变 |
| **静音裁剪阈值** | 剪掉首尾静音 | 固定 **−40 dBFS**（线性 0.01） |

### 3.2 音量条怎么算

```python
db    = 20 × log10(rms)
ratio = (db − (−70)) / ((−20) − (−70))     # 即 (db + 70) / 50
ratio = 限制到 [0, 1]
```

- 底噪 −78 dBFS → ratio = 0（不显示）
- 正常说话约 −20 dBFS → ratio = 1（满格）

### 3.3 自适应 VAD 门限怎么算

**每一轮开始前先安静录 0.6 秒**，算出噪声基线 N：

```python
N = 分块 RMS 的 dB 值的中位数      # 分块 50 ms，用中位数抗突发噪声
门限 T = max(N + margin, floor)
```

| 参数 | 代码默认 | **服务实际使用** | 含义 |
|---|---|---|---|
| `margin` | 8 dB | **15 dB** | 比噪声高多少才算说话 |
| `floor` | −40 dBFS | **−35 dBFS** | 绝对下限 |

**举例**（服务配置：margin 15、floor −35）：

| 环境噪声 | 计算 | 门限 | 正常说话 −20 dBFS 能过吗 |
|---|---|---|---|
| −55 dBFS | max(−40, −35) | **−35** | ✅ |
| −42 dBFS | max(−27, −35) | **−27** | ✅ |
| −32 dBFS | max(−17, −35) | **−17** | ❌ 会被判成静音 |

> ⚠️ **门限的物理上限 = 说话音量 − 环境噪声（即信噪比）。**
> 环境太吵时 margin 调得越高，越容易把说话本身也判成静音。

### 3.4 为什么必须用自适应（踩过的坑）

早期用**固定阈值** `ratio >= 0.18`，反算成 dB 是 **−61 dBFS**。

```
环境噪声 −32 dBFS → ratio = 0.76
0.76 远大于 0.18  →  检测器永远判定「有人在说话」
                  →  静音永远累计不起来
                  →  录音只能等时长上限，白等十几秒
```

### 3.5 其他与电平相关的参数

| 参数 | 值 | 说明 |
|---|---|---|
| **录音前的校准时长** | 0.6 秒 | 屏幕提示「保持安静」 |
| **噪声分块长度** | 50 ms | 计算噪声基线的窗口 |
| **电平平滑系数** | 0.75 / 0.25 | 指数平滑，避免单块 21 ms 抖动 |
| **最少有声时长** | 0.2 秒 | 累积这么久才开始计静音 |
| **静音裁剪阈值** | 0.01（线性） | = −40 dBFS，两端各留 0.3 秒 |
| **麦克风增益** | 28 / 35 | 出厂值是 **0**，必须显式设置 |
| **扬声器音量** | 37 / 37 | 满量程 |

### 3.6 实测电平参考

| 场景 | 峰值 | RMS |
|---|---|---|
| 安静房间底噪 | — | −70 ~ −78 dBFS |
| 正常说话（增益 28） | −3 ~ −6 dBFS | −19 ~ −28 dBFS |
| 说话很轻/离得远 | −15 dBFS | −40 dBFS 以下（识别容易失败） |

> 若看到「环境噪声基线 −68 dBFS」这种数字，说明**麦克风可能没接通** —— 真实房间底噪不会这么低。

## 4. 完整流程（USB 触发模式）

```
① 待机
   屏幕：「请插上声卡」
   程序：每 0.4 秒检查 /proc/asound/card*/usbid 是否有 0d8c:0014

② 插上声卡
   程序：等待设备枚举 → 重新解析 ALSA 卡号和 sounddevice 索引
        → 设置麦克风增益 28、扬声器音量 37
   声音：一声短嘀（1200 Hz）
   屏幕：音量条

③ 说话
   录音：48 kHz 单声道，实时电平驱动音量条

④ 拔下声卡
   录音：检测到缓冲区 0.5 秒没有新数据 → 判定设备断开 → 立即结束
   处理：裁掉首尾静音（阈值 −40 dBFS，各留 0.3 秒）

⑤ 识别
   SenseVoice：48 kHz → 内部重采样到 16 kHz → 输出文字
   耗时：0.3 秒左右（17~20 倍速）
   屏幕：「识别中」

⑥ 指令判断（顺序不能乱）
   ├─ 命中「曼波关机 / 瓦瓦关机」 → 断电
   ├─ 命中切换词且音色不同       → 换音色 → 回 ①
   └─ 普通句子                   → 继续 ⑦

⑦ 显示
   屏幕：整屏只显示识别到的这句话

⑧ 变声（按当前音色二选一）
   ├─ 瓦瓦：DSP 相位声码器 → 0.4 秒
   └─ 曼波：CosyVoice2     → 8~20 秒（上半文字 + 下半进度条）

⑨ 等待播放
   屏幕：上半显示识别文字 / 下半提示「请插上声卡播放」
   程序：等待声卡重新插入 → 重新解析设备

⑩ 播放
   从声卡输出变声结果

⑪ 收尾
   屏幕：「请拔下声卡」→ 拔下后回 ①
```

## 5. 模型清单

| 模型 | 作用 | 参数量 | 精度 | 跑在哪 | 耗时 |
|---|---|---|---|---|---|
| **SenseVoice** | 语音 → 文字 | 234 M | int8 | CPU | 0.3 s / 6 秒音频 |
| **DSP 相位声码器** | 波形变调 + 共振峰搬移 | **0** | — | CPU（numpy） | 0.4 s / 6 秒音频 |
| **CosyVoice2** | 文字 → 带指定音色的语音 | 约 781 M | W8A8 + FP16 | **NPU** | 8~20 s |
| MeloTTS | 普通语音合成 | 约 43 M | FP16 | NPU | 4.5 倍速（备用） |

| 语音 tokenizer | 123.7 M | NPU |
| Flow Estimator | 约 86.9 M | NPU2 |

| HiFT Decoder | 约 20.6 M | NPU2 |

## 6. 两条变声路线对照

| 项目 | 瓦瓦（DSP） | 曼波（CosyVoice） |
|---|---|---|
| 输入 | **波形** | **文字** |
| 输出 | 波形 | 波形 |
| 保留原语调 | ✅ 完整保留 | ❌ 丢失 |
| 复现特定音色 | ❌ 只能整体升调 | ✅ 可克隆任意音色 |
| 参数量 | **0** | 781 M |
| 处理耗时 | **0.4 秒** | 8~20 秒 |
| 峰值内存 | 约 0.4 GB | 约 1.6 GB |
| 可调参数 | 5 个预设（+8 ~ +25 半音） | 参考音频决定 |
| 实时性 | 快 15 倍 | 慢于实时 |

**为什么两条都留着**：取舍恰好互补，演示时对比着讲最能说明「信号处理」和「神经网络」的本质区别。

## 7. 语音指令

| 说什么 | 效果 |
|---|---|
| 「我是曼波」/「切换到音色1」/「哈基米」 | 切到曼波音色 |
| 「我是瓦瓦」/「切换到音色2」 | 切到瓦瓦音色 |
| 「**曼波关机**」（曼波音色下） | 断电 |
| 「**瓦瓦关机**」（瓦瓦音色下） | 断电 |
| 任意句子 | 用当前音色念出来 |

**同音容错**（ASR 实测收到的错误写法）：

```
曼波 → 慢播 / 漫播 / 漫步      用 [曼慢漫满蛮蔓][波播拨博簸步] 匹配
瓦瓦 → 娃娃 / 哇哇             用 [瓦娃哇挖袜][瓦娃哇挖袜] 匹配
音色1 → 银色1                  用 [音银][色瑟][1一壹] 匹配
```

**幂等规则**：当前已是该音色时，说的话当普通句子念出来，不重复切换。

## 8. 部署

```bash
# 一键应用（重装服务 + 重启 + 校验版本）
cd ~/proj/kskbl
sudo bash deploy/apply.sh

# 看日志
journalctl -u kskbl -f

# 停止（手动调试前必须停，否则抢屏幕和声卡）
sudo systemctl stop kskbl
```

**服务实际参数**：

```
--trigger usb          USB 声卡插拔触发
--usb-id 0d8c:0014     声卡 VID:PID
--duration 30          最长录音（保险）
--silence-stop 0       关闭静音自动停（只听拔卡）
--noise-margin 15      说话门限 = 噪声 + 15 dB
--speech-floor -35     说话门限的绝对下限
--mic-gain 28          麦克风增益
--voice wawa           默认音色
```

## 10. 三句话记住这个项目

```
第一句：软件是一个状态机加五个模块，调度和处理分离，全部跑在板子上。
第二句：变声有两条路 —— DSP 零参数 0.4 秒但改不了音色，CosyVoice 781 M 能克隆音色但丢语调。
第三句：识别 234 M 跑 CPU 17~20 倍速，克隆 781 M 跑 NPU 首包 1.9 秒。
```
