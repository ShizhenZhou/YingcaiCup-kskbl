## 一、你已有的东西怎么用（这是能减配的关键）

### 1. AE013B 散热器 = Radxa Heatsink 6240B → **不需要再买风扇**
官方规格确认：62×40×9mm 铝制，**风扇转速 7000 RPM ±10%，2-Pin 1.25mm 接口，5V DC**，包装内含 3 片导热硅胶垫（[官方规格页](https://docs.radxa.com/en/accessories/heatsink-case/heatsink-6240b)）。
→ 直接接到板子的 FAN 接口，跑 `rsetup` → Hardware → Thermal governor 设为 `power_allocator` 或 `step_wise`（60℃ 起转）。
→ **省 ¥20–30。**

### 2. HD-05 5V/5A = 25W → **可以给板子供电，但必须走 40Pin**
Radxa 官方文档《Power Board Via 40 PIN GPIO》**正是用 ROCK 5B+ 做示例**：接 5V 电源到 40Pin 的 5V/GND，官方明确说这个路径**最大支持 25W**（[官方文档](https://docs.radxa.com/en/rock5/rock5b/hardware-design/power_board_from_40pin)）。

你的 HD-05 是 5V/5A = **恰好 25W，正好卡在上限**。

- 若 HD-05 输出是 **USB-C 口（固定 5V）**：直接插板子那个「仅供电」的 USB-C 口即可（官方允许固定电压 5V–20V 输入）。
- 若是 **DC 圆头 / 接线柱**：走 40Pin —— **5V 接 Pin 2 和 Pin 4 各一根线**，**GND 接 Pin 6/9/14/20（尽量多接几根）**。
- ⚠️ **上电前先用万用表量空载电压，必须稳定在 5.0–5.2V 之间**；官方警告超过 5.2V 会烧板。
- → **省掉 ¥60 的 PD 充电器（暂时）。**

### 3. 那条 25W 上限，决定了整个减配方案的纪律
官方原话：5B+ 要 40W 是因为「两块 SSD + 4G 模块」要额外供电。你**不装 NVMe、不装 4G**，只从 microSD 启动，25W 是够的。但必须守纪律（见第五节），否则会随机掉电重启。

## 五、25W 供电下必须遵守的 6 条纪律

1. **不装 NVMe、不装 4G 模块、不接移动硬盘。** 只从 microSD 启动。
2. **灯带用独立的 5V 3A 电源**，绝对不从 40Pin 的 5V 取电。灯带 GND 与板子 GND **必须共地**。
3. **供电线用 22AWG 或更粗，5V 走 2 根、GND 走 4 根以上。** 官方明确说接触电阻大就上不到 25W。
4. **上电前量电压**：稳定 5.0–5.2V，绝不能超 5.2V。
5. **USB 声卡是唯一的外设负载**，别再插大功率 USB 设备（4G 网卡、USB 硬盘）。
6. **压力测试验证**：跑 `stress-ng --cpu 8 --timeout 600s` 同时跑一段 NPU 推理，观察 10 分钟不重启。**一旦重启，立刻上 65W PD 充电器**（¥60），这是唯一无法绕过的硬约束。

> 例外：如果 HD-05 输出是 USB-C 口且能稳定输出 5A，可以直插板子的供电 USB-C 口，省掉接线的麻烦。

## 六、变声链路在 ¥400 下的现实预期

- **音频通路**：领夹麦 → USB 声卡 → ALSA → 推理 → USB 声卡 → 耳机。**全有线，绝不用蓝牙做音频**（BT 延迟 150–300ms，必然回声）。
- **模型存储**：SD 卡加载 .rknn 模型，首次加载约几秒，之后常驻内存（16GB RAM 完全够）。
- **转换工具链**：`rknn-toolkit2` **只在 x86_64 Linux 上跑**。你需要一台笔记本装 WSL2 或 Ubuntu 双系统 —— 这是"必需材料"但不用花钱，务必提前准备好，并先在 PC 上跑通链路再移植。
- **低延迟靠参数不靠钱**：`plughw` 直连、48kHz/16bit、period 设 240–480 帧、绕开 PulseAudio 重采样。
- **灯效链路**：Python 算出每帧颜色 → USB 串口发 20–60 字节给 ESP32-C3 → ESP32 用 RMT 硬件外设精确输出 WS2812 时序。这样 Linux 抖动完全不影响灯带。
- **备选技巧**：如果不想用 74AHCT125，可以在灯带 VDD 串一只二极管（SS34/1N5408），VDD≈4.4V，逻辑门限降到 3.1V，3.3V 直驱就稳了。省 ¥5，但亮度略降。

## 七、什么时候该加钱升级

按性价比排序：

1. **65W PD 充电器（¥60）** —— 只要出现一次掉电重启就立刻买，优先级高于一切。
2. **NVMe 256GB SSD（¥120-150）** —— 想缩短模型加载时间、或要存数据集时。注意**不支持 M.2 SATA**。
3. **SK9822 灯带（¥60）** —— SPI 独立时钟，可以彻底扔掉 ESP32 执行器。
4. WiFi 天线（¥20）—— 需要无线演示时。
