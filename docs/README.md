## 速查

### 从 Windows 笔记本连接板子

```powershell
ssh -i $HOME\.ssh\rock5b radxa@192.168.8.11
```

- 主机名 `rock-5b-plus`，地址 `192.168.8.11`
- 用户名 `radxa`，密钥：`%USERPROFILE%\.ssh\rock5b`

> **PowerShell 引号陷阱**：PowerShell 会剥掉远程命令串的外层双引号。
> 远程命令里禁用 `"`、`#`、`$`、`()`，用 `===XXX===` 做分隔。

### 板子上最常用的命令

```bash
# 部署（改完代码必做）
cd ~/proj/kskbl && sudo bash deploy/apply.sh

# 日志
journalctl -u kskbl -f

# 声卡（编号会漂移，永远用卡名或 VID:PID）
cat /proc/asound/cards
for p in /proc/asound/card*/usbid; do echo "$p = $(cat $p)"; done

# 关闭 WiFi 省电（重启后失效）
sudo iw dev wlP2p33s0 set power_save off
```

## 五条必须记住的铁律

1. **改完代码必须重启服务** —— systemd 里的进程不会自动重载代码。用 `apply.sh` 并核对版本时间。
2. **声卡永远按名字或 VID:PID 找，不要用卡号** —— 每次插拔都可能变（见过 3/4/5）。
3. **音色资产放持久目录** `~/proj/voices/`，不能放 `/tmp` —— 会被系统 tmpfiles 清掉。
4. **`pkill -f` 会杀掉自己** —— 用方括号技巧 `tools/foo[.]py`，或按 PID 杀。
5. **关机指令必须带音色名**（「曼波关机」/「瓦瓦关机」）—— 防误触断电。
