## 速查

### 从 Windows 笔记本连接板子

```powershell
ssh -i $HOME\.ssh\rock5b radxa@192.168.1.100
```

- 主机名 `rock-5b-plus`，地址 `192.168.1.100`
- 用户名 `radxa`
- 密钥：`%USERPROFILE%\.ssh\rock5b`

> **PowerShell 引号陷阱**：PowerShell 会剥掉远程命令串的外层双引号。
> 写远程命令时用**内层单引号**：
> ```powershell
> ssh -i $HOME\.ssh\rock5b radxa@192.168.1.100 "python3 -c 'print(1)'"
> ```

### 板子上最常用的命令

```bash
# 声卡（编号会漂移，永远用卡名）
cat /proc/asound/cards
amixer -c rockchipes8316 controls | grep iface=MIXER

# 放音 / 录音
timeout 6 speaker-test -c 2 -t sine -f 440
arecord -D plughw:CARD=rockchipes8316,DEV=0 -f S16_LE -r 48000 -c 2 -d 3 /tmp/mic.wav

# 无线链路
iw dev wlP2p33s0 link

# 保存混音器状态（重启自动恢复）
sudo alsactl store
```

---

## 三条必须记住的铁律

1. **声卡永远用卡名 `rockchipes8316`，不要用 `-c 4` 这类编号** —— 重启后会漂移。
2. **`amixer sget` 看不到真正的控件名** —— 全名控件必须用 `cget` / `cset`（见音频笔记第 3 节）。
3. **音视频程序直连硬件设备 `plughw:CARD=rockchipes8316,DEV=0`** —— 绕开 PipeWire，音量可控且延迟更低。
