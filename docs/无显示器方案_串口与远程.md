# 没有显示器怎么办 · 串口 / SSH / 远程桌面
### 配套：Windows 11 笔记本 · ROCK 5B+ · 三人小队

---

## 一、直接回答你的两个问题

### Q：笔记本显示屏能用吗？
**分两种情况：**

| 方式 | 能不能用 | 说明 |
|---|---|---|
| **笔记本 HDMI 口直连板子 HDMI** | ❌ **不能** | 笔记本的 HDMI 口几乎都是**输出口（HDMI OUT）**，只能往外送画面，不能往里收 |
| **USB HDMI 采集卡** | ✅ 能 | 采集卡 ¥30–60，插笔记本 USB，用 OBS 或 Windows「相机」应用就能看到板子的画面（见路线 D） |
| **xrdp 远程桌面** | ✅✅ **最推荐** | 用 Windows **自带的**「远程桌面连接」，零成本、响应好（见路线 C） |

### Q：那用网口连接行不行？
✅ **行，而且这是主力方案。**

而且有个好消息——官方文档原话：

> **"The SSH service is automatically enabled when no monitor is connected during the first boot."**
> （首次启动时如果没有接显示器，SSH 服务会自动开启）

也就是说：**你不接显示器反而是好事**，SSH 会自动开着。你只需要解决一个问题：**怎么知道板子的 IP 地址**。

## 二、四条路线对比

| 路线 | 需要什么 | 成本 | 用途 |
|---|---|---|---|
| **A. 串口控制台** | CH340 模块 | **¥11** | ⭐ **第一次开机必用**：看启动日志、拿 IP、救砖 |

## 三、路线 A：串口控制台（第一次开机就用它）

这是**没有显示器时最可靠的一条路**：板子从通电第一毫秒开始的所有输出你都能看到，包括它有没有启动成功、IP 是多少、哪里报错。

### 1. 接线（官方文档给的引脚定义）

串口控制台就在 **40Pin 排针**上，不用找别的接口：

| 板子 40Pin | 接到 | USB-TTL 模块 |
|---|---|---|
| **GND（Pin 6）** | ↔ | **黑线 GND** |
| **TX（Pin 8）** | ↔ | **白线 RXD** |
| **RX（Pin 10）** | ↔ | **绿线 TXD** |

> ⚠️ **红色的电源线绝对不能接！** 官方文档明确标了 danger。只接三根线：GND、TX、RX。
> （注意 TX 接 RXD、RX 接 TXD，是**交叉**的）

### 2. 参数（这里有个大坑）

```
波特率  : 1500000      ← 一百五十万，不是 115200！
数据位  : 8
停止位  : 1
校验    : 无
流控    : 无
```

**⚠️ 必须买 CH340 芯片的模块。** 官方文档明确写了：
- **CP210x / PL2303x** 部分型号**有波特率限制**，可能跑不了 1.5M
- **FT232RL** 有供电问题
- 官方推荐并用 **CH340** 做示例

所以别图便宜买 CP2102，直接买 **CH340**（¥11 左右）。**这是本次采购里最容易买错的一件。**

### 3. Windows 上用 PuTTY

1. 插上模块，**设备管理器**里看是 COM 几（比如 COM3）
2. 装 PuTTY，设置：`Session` → Connection type 选 **Serial**，Serial line 填 `COM3`，Speed 填 **1500000**
3. `Serial` 分类里把 **Flow control 设成 None**
4. 点 Open → 给板子上电，就能看到滚动的启动日志

> **FAQ 里的坑**：如果能看到启动信息但**打字没反应**，就是 Hardware Flow Control 被打开了，关掉即可。

### 4. 拿到 IP

在串口里登录（默认账号 `radxa`，密码 `radxa`，以镜像文档为准），然后：

```bash
ip a
```

就能看到 `eth0` 或 `wlan0` 的 IP。**然后就可以去走路线 B 了。**

## 四、路线 B：SSH（主力工作方式）

Windows 11 **自带 OpenSSH**，不需要装 PuTTY（PuTTY 只用来做串口）：

```powershell
ssh radxa@192.168.x.x
```

### 怎么找到 IP？五种方法，按可靠性排序

| # | 方法 | 说明 |
|---|---|---|
| 1 | **串口控制台里 `ip a`** | ⭐ 最确定，推荐第一次就用这个 |
| 2 | **在 SD 卡上预配置 WiFi** | 烧完镜像后，把 SD 卡插回电脑，会出现一个 `config` 分区，里面的 **`before.txt`** 加一行：<br>`connect_wi-fi 你的SSID 你的密码`<br>插卡开机就自动连上 |
| 3 | 网线接宿舍/实验室路由器 | 登录路由器后台 → DHCP 客户端列表 → 找 `rock-5b-plus` 或它的 MAC |
| 4 | 试 mDNS | `ssh radxa@rock-5b-plus.local`（Windows 11 原生支持 `.local`，值得先试一下） |
| 5 | 网线接交换机 | 用 Advanced IP Scanner 扫网段 |

> ⚠️ **方案 2 有个前提**：ROCK 5B+ 是板载 WiFi，但**必须接天线**。不接天线的话信号极差、基本连不上。如果你打算走 WiFi，天线（¥15–25）就得买；如果走网线就不用买。

## 五、路线 C：xrdp —— 用 Windows 自带远程桌面当显示器 ⭐

**这是"笔记本当显示器"的最优解**，零成本、零额外软件、比 VNC 流畅。

在板子上（通过 SSH）：

```bash
sudo apt update
sudo apt install -y xrdp
sudo systemctl enable --now xrdp
```

然后在 Windows 上：
- 按 `Win + R` → 输入 `mstsc` → 回车（这就是**自带的**「远程桌面连接」）
- 计算机填板子 IP → 连接
- xrdp 登录界面里选 session 类型（选 Xorg / console），输入 `radxa` / 密码

之后你就在笔记本窗口里拥有了完整的板子桌面，鼠标键盘都用笔记本的。**你那个华硕 USB 键盘可以先留着，暂时用不上。**

## 六、路线 D（可选）：USB HDMI 采集卡

如果你就是想看到真实的开机画面（比如 HDMI 无输出的排查、或者以后答辩要接投影）：

- 笔记本的 HDMI 口**不能用**（是输出口）
- 买一个 **USB HDMI 采集卡**（认准 **MS2109** 芯片，¥30–60）
- 插到笔记本 USB 上，Windows 会多出一个「USB Video」摄像头设备
- 用 **OBS Studio**（免费）或 Windows 自带的「相机」应用打开，就能看到板子的 HDMI 输出
- 你手上的华硕 USB 键盘插到板子上 → 完整的「显示器 + 键盘」体验
- 延迟约 100–200 ms，做配置完全够用

**买的话记得同时配一根 HDMI 线。**

## 七、顺手教你一个零成本「验活」技巧

板子点不亮、又没显示器，怎么判断是板子坏了还是系统没烧好？官方 FAQ 给了方法：

1. 拔掉 microSD / NVMe，断电
2. **按住 MASKROM 按钮**
3. 用 **USB-A 转 USB-C 数据线**把板子的 USB-C 口接到 Windows 笔记本
4. **绿灯亮起 + 设备管理器里出现新 USB 设备** → 板子是活的

**所以你需要一根 USB-A 转 USB-C 数据线**（很多安卓手机充电线就是这个）。先翻翻抽屉，没有的话 ¥10 买一根。

## 八、三人小队：一块板子怎么协作

### 用 tmux 共享同一个终端 ⭐

```bash
sudo apt install -y tmux
tmux new -s work        # 第一个人创建
tmux attach -t work     # 另外两个人 SSH 进去后 attach
```

**三个人看到同一个终端、同一份输出。** 一个人操作，另两个人实时围观、随时插话。比三个人轮流问"你刚才敲了啥"高效十倍。

## 十、额外提醒：一个和供电有关的已知坑

官方 FAQ 里有一条 **"My new ROCK 5B won't boot / stuck in infinite boot loop"**：

> ROCK 5B 通过 USB-C 协商 PD 升压（9V/12V/15V/20V）来满足整机功耗，**但 PD 协商是在内核驱动里实现的**。有些电源等不到协商完成就超时断电，导致**无限重启循环**。

**这条恰好又支持了你走 40Pin 供电路线**——用 HD-05 从 40Pin 输入 5V 完全不涉及 PD 协商，反而绕开了这个坑。

官方建议的规避方法里还有一条对你也有用：**"使用更快的 SD 卡，或关闭 bootloader/内核串口控制台"**——所以 microSD 买正品 A2 是有实际意义的。

## 十一、第一次开机的最短路径（照这个走）

1. 烧镜像到 microSD（**ROCK 5B+ 专用镜像**）
2. 把 SD 卡插回电脑，在 `config/before.txt` 里加 `connect_wi-fi` 那行（走 WiFi 的话）
3. SD 卡插进板子
4. CH340 模块接 Pin 6 / 8 / 10（**不接红线**），USB 插笔记本，PuTTY 开 1500000 波特率
5. 板子上电（HD-05 走 40Pin）
6. **串口里看启动日志** ← 到这一步你就成功了大半
7. 登录 `radxa` / `radxa` → `ip a` 拿 IP
8. 笔记本 PowerShell：`ssh radxa@<IP>`
9. 装 xrdp，需要图形界面时用 `mstsc`

**预期耗时：熟练后 20 分钟，第一次做留一个下午。**
